# 📘 StudyHub - 青チャート解説まとめ＆学習ダッシュボード

数研出版の公式デジタル解説動画教材（新課程版 青チャート 数学I+A / II+B / III / C）を整理・体系化し、日々の自学自習を強力にサポートするシンプルで使いやすい勉強アプリです。

---

## 🌟 主な機能

### 1. 📘 青チャート 4冊の全解説教材を瞬時検索＆アクセス
- **数学Ⅰ＋A** (12章・全864問)
- **数学Ⅱ＋B** (12章・全802問)
- **数学Ⅲ** (8章・全446問)
- **数学C** (7章・全454問)
- **合計 2,566問**の例題・解説動画・サポートコンテンツを完全収録。
- 例題番号（例: `例題1`, `重要例題 50`）やキーワード（`2次不等式`, `ベクトル`, `積分`）で即座に絞り込み可能。
- 各カードの「解説」ボタンから、数研出版の公式デジタル教材ビューアー（CDS Chart）へダイレクトにジャンプできます。

### 2. ✅ 学習ステータス管理＆メモ機能
- 各問題ごとに **「未着手」「⚠️ 要復習」「✅ 習得済」** をワンクリックで記録。
- **⭐ お気に入り（ブックマーク）**: テスト直前や頻出問題をピン留め。
- **📝 学習メモ**: 間違えやすいポイントや解法のコツを問題ごとに保存。

### 3. 📊 学習進捗ダッシュボード
- 科目ごとの習得進捗率（％）をリアルタイム可視化。
- **⚠️ 要復習リスト**: つまずいた問題を科目横断で一覧表示し、直前の見直しや総復習を即座に開始可能。

### 4. ⏱️ ポモドーロ集中タイマー
- 25分集中 ＋ 5分小休憩のポモドーロタイマーを常備。
- 本日の達成セッション数を自動カウント。終了時には心地よいチャイム音で通知。

### 5. 📂 カスタム資料まとめ（自由追加）
- 青チャート以外にも、英語・物理・化学などの参考書、YouTubeの解説動画リンク、自作PDF、Webサイトなどを自由に追加・管理可能。

### 6. 💾 データの永続化＆バックアップ
- ブラウザ（`localStorage`）への自動保存に加え、ローカルPythonサーバー稼働時はディスク（`user_study_data.json`）にも自動バックアップ。
- ワンクリックでJSONファイルとして書き出し（エクスポート）＆復元（インポート）が可能。

---

## 🚀 起動方法

### 方法 A: ダブルクリックで起動（一番簡単・推奨）
1. フォルダ内の **`start_app.bat`** をダブルクリックします。
2. 自動的にブラウザが立ち上がり、アプリが開きます！

### 方法 B: Pythonコマンドで起動
ターミナルまたはPowerShellで以下を実行します：
```bash
cd study-hub
python server.py
```
`http://localhost:8000` にアクセスします。

### 方法 C: ブラウザで直接開く（サーバー不要）
フォルダ内の **`index.html`** をダブルクリックして、Google Chrome や Microsoft Edge などのブラウザで直接開いてもすべての機能が動作します。
